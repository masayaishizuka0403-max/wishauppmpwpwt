# Wishlist iPhone PWA

Android版Wishlistをもとにした、iPhoneのSafariからホーム画面へ追加できるPWAです。

## 使える機能

- 発売前のカウントダウンと「NOW ON SALE」表示
- Countdown内のストアボタン（ショッピングカート）
- 発売済みカードを左スワイプして購入済みにする操作
- 商品画像、商品名、説明、価格、URL、発売日時の登録・編集
- リスト作成・名前変更・削除、購入済み、最近削除した項目、検索
- ブラウザ内へのデータ保存と、アプリシェルのオフラインキャッシュ

## iPhoneへの追加

1. HTTPSに対応したWebサーバーへ、このフォルダーの内容を配置します。Vercelではそのままデプロイできます（api/product.jsはVercel Functionsとして動作します）。
2. iPhoneのSafariでデプロイ先URLを開きます。
3. 共有ボタンから「ホーム画面に追加」を選びます。

ホーム画面のアイコンから開くと、ブラウザーのアドレスバーを隠したアプリ風表示になります。

## 保存と制約

登録内容と選択画像は、そのiPhoneのSafari内に保存されます。Androidアプリとは自動同期されません。端末変更やSafariのデータ消去に備え、必要なアイテム画像は元画像も保管してください。

商品ページの自動取得には、同じHTTPSサイト上でapi/product.jsが動作する必要があります。ログイン必須、JavaScriptで後から商品情報を表示するサイト、アクセスを拒否するサイトでは取得できないことがあります。

カウントダウン表示はPWAを開いている間に更新されます。iOSのバックグラウンド通知はこのパッケージには含めていません。
