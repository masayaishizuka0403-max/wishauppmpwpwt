Wishlist iPhone PWA (試用版)

このZIPは署名済みIPAではなく、ホーム画面に追加できるWebアプリのファイルです。

iPhoneに入れる方法:
1. ZIPを解凍する。
2. 中身のファイルをHTTPS対応の静的Webホスティング（GitHub Pages、Netlify、Vercelなど）にアップロードする。
3. iPhoneのSafariで公開URLを開く。
4. Safariの共有メニューから「ホーム画面に追加」を選ぶ。
5. ホーム画面のWishlistアイコンから起動する。

注意:
- ファイルアプリからHTMLを直接開くだけでは、通常PWAとしてインストールできません。
- 登録データはその端末のブラウザ内に保存されます。同期・バックアップは未実装です。
- 商品画像は端末から追加できます（2MBまで）。
- 通知や完全自動購入は未実装です。
- カウントダウンはmm:ss形式（60分以上は分が増加）で、画面表示中に更新されます。
- デモ用商品URLは商品個別ページではありません。適宜登録してください。
